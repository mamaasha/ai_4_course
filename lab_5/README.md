# Лабораторная лабора №5

**Тема:** Проведение исследований с градиентным бустингом

---

## 2. Бейзлайн

* **Классификация:** tf-idf + `HistGradientBoostingClassifier` на урезанном сбалансированном наборе. Accuracy ~0.60, macro F1 ~0.61.
* **Регрессия:** базовый `GradientBoostingRegressor` с минимальным препроцессом (imputer + scaler + OneHot). MAE ~517, MSE ~1.58e7 — заметно хуже линейных моделей.

---

## 3. Улучшенный бейзлайн

* **Классификация:** эмбеддинги + балансировка классов + Optuna-подбор параметров бустинга. Accuracy ~0.79, macro F1 ~0.80.
* **Регрессия:** очищенные данные и Optuna для `GradientBoostingRegressor`. MAE ~118.8, MSE ~2.27e4, R² ~0.90.

---

## 4. Собственная реализация

* **Классификация:** упрощённый градиентный бустинг (one-vs-rest). Accuracy ~0.73, macro F1 ~0.73 — ниже тюнинга, но выше бейзлайна.
* **Регрессия:** `SimpleGradientBoosting` (свои деревья). MAE ~118.6, MSE ~2.16e4, R² ~0.91 — близко к библиотечной версии.

---

## Кратко итоги лр 1–5 

* **Классификация:** лучший результат дают ансамбли — случайный лес (лр4) и градиентный бустинг (лр5) ~0.79–0.80 accuracy/macro F1; KNN/логрег и одиночные деревья хуже. Балансировка + эмбеддинги/TF-IDF критично.
* **Регрессия:** наибольший прирост дали бустинг и тюнинг леса (MAE ~118, R² ~0.90); KNN из лр1 заметно хуже (MAE ~154), линейная/решающая дерево — ещё ниже. Препроцесс и Optuna сильно влияют на качество.

**ИТОГ итога:** более тяжёлые модели (деревья, бустинг) дают ощутимый прирост, но обучаются и подбираются намного дольше, чем лог/лин регрессия
