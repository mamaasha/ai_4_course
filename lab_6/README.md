# Лабораторная лабора №6

**Тема:** Проведение исследований с моделями компьютерного зрения (классификация изображений)

---

## 1. Начальные условия

* **Датасет:** `sshikamaru/fruit-recognition` (Kaggle)
* **Почему этот датасет:** понятная визуальная задача, удобно проверять ошибки модели глазами + многоклассовость
* **Метрики:**
  * `Accuracy` - общая доля правильных предсказаний
  * `Macro F1` - качество по всем классам с одинаковым весом (важно при дисбалансе)

---

## 2. Бейзлайн

* **Модели из torchvision:** `resnet18` (CNN) и `vit_b_16` (Transformer)
**Вывод:**
Бейзлайн получился стабильным и рабочим: у обеих моделей на графиках видно нормальное обучение (loss снижается, accuracy и macro F1 растут).
По итоговым метрикам baseline сильнее оказался `vit_b_16` (test accuracy до **0.9647**, macro F1 до **0.9615**), при этом `resnet18` тоже даёт уверенный результат (accuracy **0.7859**, macro F1 **0.7495**) и остаётся хорошей базовой точкой сравнения.

---

## 3. Улучшение бейзлайна

* Проверялись гипотезы:
  * аугментации
  * регуляризация
  * более аккуратный `lr` для обучения головы

* **Результат после улучшения (test):**
  * `resnet18`: accuracy **0.7859 -> 0.8665** (+0.0806), macro F1 **0.7495 -> 0.8590** (+0.1095)
  * `vit_b_16`: accuracy **0.7935 -> 0.9748** (+0.1814), macro F1 **0.7335 -> 0.9727** (+0.2392)

**Вывод:**
После улучшения обе модели заметно выросли. По графикам видно стабильное обучение: loss падает, accuracy и macro F1 растут без резких провалов. Лучшей моделью среди `torchvision` стала `vit_b_16`.

---

## 4. Собственная реализация

* Свои модели:
  * `SimpleCNN`
  * `TinyPatchTransformer`
* Обучение бейзлайна и с улучшенными настройками
* Сравнение с моделями `torchvision`

* **Результаты своих моделей (impl_baseline, test):**
  * `SimpleCNN`: loss **0.23267**, accuracy **0.93199**, macro F1 **0.92560**
  * `TinyPatchTransformer`: loss **0.31416**, accuracy **0.89421**, macro F1 **0.88573**

* **Результаты улучшенных своих моделей (impl_improved, test):**
  * `SimpleCNN`: loss **0.27667**, accuracy **0.96474**, macro F1 **0.96256**
  * `TinyPatchTransformer`: loss **0.10228**, accuracy **0.98237**, macro F1 **0.97999**

**Вывод:**
После добавления техник улучшенного бейзлайна обе самописные модели сильно выросли. `TinyPatchTransformer` - самая крутая модель

---

## Итог

* Улучшение пайплайна (аугментации + регуляризация + настройка обучения) дало большой прирост качества для всех групп моделей
* Среди моделей `torchvision` лучшей стала `vit_b_16` после улучшения: accuracy **0.9748**, macro F1 **0.9727**
* Среди самописных моделей лучшей стала `TinyPatchTransformer` после улучшения: accuracy **0.9824**, macro F1 **0.9800**
* Основной прирост дал именно этап улучшения
