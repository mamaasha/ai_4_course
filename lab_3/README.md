# Лабораторная лабора №3

**Тема:** Проведение исследований с решающим деревом

---

## 2. Бейзлайн

* **Классификация:** tf-idf + `DecisionTreeClassifier`. Accuracy ~0.67, macro F1 ~0.65 — заметно хуже логистической регрессии
* **Регрессия:** базовый `DecisionTreeRegressor` с минимальным препроцессом. MAE ~562, MSE ~1.6e7
---

## 3. Улучшенный бейзлайн

* **Классификация:** Optuna-подбор `max_depth`, `min_samples_split/leaf`
* **Регрессия:** чистые данные + Optuna. MAE ~131.5, MSE ~3.17e4 — качество выросло в разы.

---

## 4. Собственная реализация

* **Классификация:** свой Decision Tree на обрезанном датасете (эмбеддинги)
* **Регрессия:** самописный регрессионный вариант на препроцессенных признаках. MAE ~138, MSE ~3.38e4 — близко к результату sklearn
